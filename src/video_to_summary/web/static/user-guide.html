VTS 使用指引

粘贴视频链接或选择本地文件，VTS 优先直接使用视频自带字幕生成笔记——没有字幕时才转写。所有数据都保存在你自己的机器上。

1🔗粘贴链接YouTube / B 站链接，或本地音视频文件
→
2🎬提取内容有字幕直用零成本；无字幕才转写
→
3📝生成笔记结构化总结 + 转写全文 + SRT 字幕
01

快速上手

打开控制台（默认 http://127.0.0.1:8080），三步完成第一个任务。正在读这份手册，说明服务已经跑起来了。

🚀 第一次任务

  1. 「设置 → LLM 配置」填入你的 OpenAI 兼容端点与 Key；
  2. 「新建总结」粘贴视频链接，选好总结模板（默认「通用」即可）；
  3. 点开始，实时查看进度；
  4. 完成后得到 Markdown 笔记，可在线编辑、打标签、全文检索。
没配 Key 也能用：视频自带字幕时照常出完整笔记，全程零成本；无字幕的视频只跳过总结，仍产出转写原文，之后补上 Key 点「重新生成」即可。

🧭 控制台界面

🎬新建总结链接 / 本地文件 / 上传三种来源
📡任务状态进行中与失败任务的进度
🗂️历史任务检索、结果查看与导出
⚙️设置LLM、字幕策略、模板、标签
02

创建任务

「新建总结」里三种来源任选其一；标题不填会自动取名（解析到视频真实标题后自动回填）。

🌐 视频链接

  • 粘贴 B 站、YouTube 等站点的视频地址，点开始即可；
  • 有字幕的视频最快最省：直接用字幕出稿，不下载、不转写；
  • 需要登录态的内容（B 站 AI 字幕、会员视频等）先配好 cookies，见设置与模板。

📁 本地文件

  • 填本机音视频文件的路径，或点「浏览…」逐级挑选；
  • 支持常见视频与音频格式（mp4 / mkv / mov / mp3 / wav / flac 等）；
  • 你的本地文件永远不会被 VTS 删除——删除任务只清理它自己的产物。

📤 上传文件

  • 服务部署在远程 / Docker 时，容器看不到你本机的文件——点「上传本地文件…」，选完即自动上传并创建任务；
  • 单文件默认上限约 2GB；本机部署不需要上传，「浏览…」直接读取。

🏷️ 标签与总结模板

  • 标签：创建时随手输入，之后在历史页按标签筛选；
  • 总结模板：决定笔记的组织方式，默认「通用」，创建时可按次选择。
03

配置 LLM

转写与总结都走你自己配置的 OpenAI 兼容端点（DeepSeek、SiliconFlow、本地 vLLM / Ollama 均可）。没有账号、没有订阅，Key 只存在你自己的机器上。

🎛️ 两个槽位

槽位什么时候需要
推理模型生成总结（开启文本润色时也用它）
语音识别模型仅当视频没有字幕、需要转写时

每个槽位填三项：base_url（接入地址）、api_key、model（模型名）。只用字幕出稿的话，一个 Key 都不需要。

⌨️ 怎么配

  1. 「设置 → LLM 配置」，填好点保存，立即生效；
  2. 习惯环境变量的话，也可以写进仓库根目录的 .env（SUMMARY_API_KEY 等）后重启服务，或点「从 .env 导入」一次性迁入。
Key 的安全：Key 加密落库，界面只显示掩码，不会明文返回。
04

任务与结果

「任务状态」看进行中与失败的任务，「历史任务」查看全部结果——支持全文检索与标签筛选。

🔄 状态与操作

状态你能做什么
等待 / 运行中「停止」——在当前阶段结束边界安全中止，不会留半写文件
已完成查看 / 编辑 / 导出 / 重新生成 / 删除
失败 / 已停止「重试」（可换总结模板）或「删除」

失败时看到的是一句话的可行动提示；完整细节在「处理过程」事件链里。

📄 你会得到

  • 总结：结构化 Markdown 笔记——可在线编辑，保存后显示「已编辑」徽标；
  • 转写全文 + SRT 字幕 + 分段：标准文本文件，可单独导出；
  • 导出：笔记下载为 Markdown 附件；
  • 重新生成：清空产物按当前配置重跑（转写命中缓存不重复消耗），可顺手换个模板；编辑稿会随之失效。

🔍 检索与备份

  • 搜索：直接搜转写正文与总结内容，命中处高亮；
  • 标签：按标签过滤历史列表；
  • 导出 / 导入历史：把全部任务连同产物打包成 zip，换机器一键还原。
05

设置与模板

设置页四个页签：任务默认、LLM 配置、总结模板、标签管理；「导出日志」在页面顶部。

📝 字幕策略（任务默认）

视频自带字幕时跳过「下载音频 + 转写」，更快更省：

  • 有字幕就用（人工优先，没有则转写）——默认推荐；
  • 仅用人工字幕（没有则转写）；
  • 关闭（始终下载 + 转写）。

📚 总结模板

内置 10 种（只读，创建任务时可按次选择）：

通用（默认） 精简笔记详细笔记教程笔记 学术笔记会议纪要商业分析 小红书笔记生活随笔任务清单

想要自己的风格？点「＋ 新建模板」，用一段话描述「总结什么、怎么组织」即可，排版由系统统一负责。

🍪 需要登录的内容

B 站 AI/CC 字幕、会员视频，YouTube 自动字幕等需要登录态——在「设置 → 网络与访问」选择你已登录的浏览器，VTS 直接读取它的登录态：

  • 点「测试读取」可预检：只显示域名计数与登录状态，不显示任何 cookie 内容；
  • macOS 首次读取 Chromium 系浏览器会弹钥匙串授权，点「始终允许」；
  • 也可以改用 cookies 文件（环境变量 VTS_COOKIES_FILE），两者二选一。
cookies 等同账号凭据：注意保管，仅限个人使用并遵守平台服务条款。
06

常见问题

点开问题查看答案；没找到答案时，用「设置 → 导出日志」下载已自动脱敏的日志再排查或求助。

下载被拦截：B 站 412 / YouTube 429 怎么办？
这是站点风控 / 限流，不是故障。三个解法任选：① 设置环境变量 VTS_USER_AGENT 为非浏览器 UA（如 Wget/1.21.3）；② 提供登录 cookies（见设置与模板）；③ 配置代理后重试。详见仓库 docker/README.md「网络与风控」。
提示 no usable subtitle / B 站 AI 字幕拿不到？
B 站 AI/CC 字幕、YouTube 自动字幕通常需要登录态。在「设置 → 网络与访问」配好浏览器 cookies 后重试——命中字幕的任务更快且零转写成本。
任务失败提示「LLM 调用被拒绝（认证失败）」？
到「设置 → LLM 配置」逐项检查：API Key 是否正确、base_url 是否以 http(s):// 开头、模型名拼写是否为该端点支持的（如 deepseek-chat）。
任务生成了转写但没有总结？
这是无 Key 降级：推理槽没配 Key 时只出转写。补好 Key 后点「重新生成」即可，转写部分走缓存，不会重复消耗。
浏览器上传失败？
常见原因：文件类型不支持（音视频扩展名白名单），或超过大小上限（默认约 2GB）。本机部署可以不走上传，直接用「浏览…」读本地路径。
端口被占了 / 数据存在哪？
端口被占用时 web.sh 会自动顺延下一个，也可以 bash scripts/web.sh --port 8090 指定。数据都在本机：数据库（任务与配置）+ 产物目录（output/<任务id>/，Docker 在 /output 卷）。备份迁移用「导出历史 / 导入历史」。
07

数据与隐私

所有数据都保存在你自己的机器上；VTS 没有云端存储、没有遥测、没有用量上报。

🔒 安全要点

  • Key 加密落盘，界面只回掩码；诊断日志导出前自动脱敏，可放心外发；
  • 默认只监听本机——要暴露到局域网 / 公网，先设置 VIDEO_TO_SUMMARY_TOKEN 启用访问口令；
  • 单实例设计：请勿多个实例共用同一数据目录（第二个实例会被明确拒绝启动）。

🚧 能力边界

VTS 刻意保持单用户、BYOK 形态：不内置本地转写模型（只走你配置的 Whisper 兼容端点）、不内置站点扫码登录（cookies 自备）、无 PDF 导出、无多用户。可选能力由插件声明，以 GET /api/v1/capabilities 为准。
