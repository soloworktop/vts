VTS 使用指引

视频 URL → 结构化 Markdown 笔记。本页是 VTS 自带的极简说明。

1. 最快的路径：自带字幕的视频

把视频链接粘到「新建总结」即可。视频自带字幕（人工或平台自动字幕）时， VTS 直接使用字幕文本出笔记，不下载音频、不调用任何转写接口、零 API 成本， 也不需要配置任何 Key。

2. 想生成总结：配置你自己的 LLM（BYOK）

本版不自带任何模型通道，请自备任意 OpenAI 兼容端点。配置方式有两条：

  • 界面：「设置 → LLM 配置」，两个槽位——推理模型（生成总结， 开启文本润色时也用它）与语音识别模型（视频没有字幕时转写音频）， 各填 base_url / api_key / model；
  • 环境变量：LLM_API_KEY / LLM_BASE_URL / LLM_MODEL 与 OPENAI_API_KEY / ASR_BASE_URL / ASR_MODEL （写入仓库根目录的 .env 后重启服务即生效）；
  • HTTP 接口：GET / PUT /api/v1/llm 读写两个槽位 （base_url / api_key / model）。 Key 以 Fernet 加密落库，接口只回掩码值。
不配置也能用。未配置 Key 时任务不会失败：VTS 仍会产出转写原文 （.txt / .srt），只是跳过总结步骤并在处理过程里标注 summarize_skipped。补上 Key 后「重新生成」即可得到完整笔记。

3. 视频没有字幕时

需要 Whisper 兼容的转写接口：设置 OPENAI_API_KEY，或在「设置 → LLM 配置」的 语音识别模型槽位配置一个支持 /audio/transcriptions 的端点。

4. 需要登录的内容

本版不内置站点登录集成。请使用 --cookies 指定 cookies 文件， 或在「设置 → 网络与访问」里选择「浏览器 cookies」（直接读取本机浏览器的登录态）。 两者互斥，显式 cookies 文件优先。

5. 能力边界

可选能力由插件声明，以 GET /api/v1/capabilities 为准；本构建不含任何 插件，响应为空。产品范围（不做本地模型托管、不做站点登录集成、不做多用户与任何 上报机制）详见仓库根的 CONTRIBUTING.md「范围宣言」。
