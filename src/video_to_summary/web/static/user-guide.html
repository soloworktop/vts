VTS 使用指引

粘贴视频链接或选择本地文件，VTS 优先直接使用视频自带字幕生成笔记——没有字幕时才下载音频、调用你自己配置的转写接口。所有数据都保存在你自己的机器上。

1🔗粘贴链接YouTube / B 站链接，或本地音视频文件、浏览器上传
→
2🎬提取内容有字幕直用零成本；无字幕才转写（你的 Whisper 端点）
→
3📝生成笔记结构化 Markdown 总结 + 转写全文 + SRT 字幕
01

产品简介

VTS 是一个自部署的单用户工具：把视频变成结构化 Markdown 笔记。BYOK（Bring Your Own Key）——转写与总结都走你自己配置的 OpenAI 兼容端点，没有账号、没有订阅、没有用量上报。

🌐支持站点YouTube、Bilibili 等任意 yt-dlp 支持的 http(s) 站点
📥三种输入视频 URL / 本地文件路径 / 浏览器上传
📄输出内容结构化总结 + 转写全文 + SRT 字幕 + 分段信息
🏠数据在本机任务、配置、产物都保存在你自己的机器上

🪶 字幕优先，零成本路径

视频自带可用字幕（人工字幕或平台自动字幕）时，VTS 直接以字幕文本作为转写结果：不下载音频、不调用任何转写接口、零 API 成本，也不需要配置任何 Key。

🔍 提取字幕清单→ 🎬 有字幕 → 直接出稿

没有可用字幕时自动回退：下载音频 → 用你配置的 Whisper 兼容接口转写 → 生成总结。

02

安装与启动

三种形态任选：pip 安装（本机运行）、源码检出（开发/自部署）、Docker（远程服务器）。启动后浏览器打开控制台即可使用。

🐍 pip 安装（推荐）

  1. 安装：pip install vts（或从 GitHub Releases 安装指定版本 wheel）。
  2. 启动 Web 控制台：vts 是 CLI 入口；Web 服务用 python -m uvicorn video_to_summary.web.app:app --host 127.0.0.1 --port 8080，或直接用源码里的 bash scripts/web.sh（自动建 venv、装依赖、起服务）。
  3. 浏览器打开 http://127.0.0.1:8080。端口被占用时 web.sh 会自动顺延到下一个可用端口。

🐳 Docker 部署

  1. 克隆仓库后执行：docker compose -f docker/docker-compose.yml up -d --build。
  2. 数据落在 named volume（/data 数据库、/output 产物），升级镜像不丢数据。
  3. 容器内默认单 worker 启动；不要追加 --workers>1 或多副本扩容（见数据与隐私）。

🧭 控制台主界面

左侧功能导航，本手册后续章节按此展开。

🎬新建任务URL / 本地文件 / 上传三种来源
🗂️历史任务检索、标签、结果查看与导出
⚙️设置LLM 配置、任务默认、模板、标签管理
🩺导出日志自动脱敏的诊断日志，排障时附上
从源码检出直接启动且未构建前端时，首页会显示「前端尚未构建」指引页（cd web-src && pnpm install && pnpm build），API 不受影响；pip/Docker 安装自带已构建前端。
03

创建任务

新建任务支持三种来源，任选其一；标题不填会自动取名（解析到视频真实标题后自动回填），标签与总结模板可选。

🌐 URL 来源

  • 粘贴视频链接（B 站、YouTube、Twitter/X、抖音、微博、小红书等 yt-dlp 支持的站点均可）。
  • 只接受 http:// / https:// 链接；需要登录态的内容用 cookies 提供（见 设置）。
  • 任务页显示的处理进度与每个阶段的耗时；下载阶段有实时进度条，长音频转写按分片回报进度。

📁 本地文件

  • 直接填本机音视频文件的绝对路径（服务端所在机器能看到的路径）。
  • 点「浏览路径」可在面板里逐级导航挑选；桌面会话还可以唤起系统原生文件选择框（macOS / Windows）。
  • 支持格式：mp4 mkv mov avi webm flv wmv m4v mpg mpeg ts 与音频 mp3 m4a aac wav flac ogg opus。
  • 你的本地源文件永远不会被 VTS 删除——删除任务只清理它自己的产物目录。

📤 浏览器上传

给 远程 / Docker 部署用的补充入口：容器里看不到你本机的文件，把音视频从浏览器直接拖上传即可（一步完成落盘 + 建任务）。

  • 单文件上限默认 2048MB（环境变量 VTS_UPLOAD_MAX_MB 可调）。
  • 支持格式与「本地文件」一致；文件存放在服务端托管目录 uploads/<uuid>/。
  • 上传文件归服务端托管：删除任务时会连带回收，重试不受影响。

🏷️ 标签与总结模板

  • 标签（可选）：创建时输入一个或多个标签，历史页可按标签筛选、在标签管理里重命名 / 合并 / 删除。
  • 总结模板（可选）：唯一支持按任务指定的处理配置；不选则跟随全局默认「通用」。重试时也可以换模板（见 任务状态与结果）。
04

配置 LLM（BYOK）

本版不自带任何模型通道，请自备任意 OpenAI 兼容端点（OpenAI、DeepSeek、SiliconFlow、本地 vLLM / Ollama 均可）。两个槽位互相独立。

🎛️ 两个槽位

槽位用途要求
推理模型生成总结；开启文本润色时也用它OpenAI 兼容 /chat/completions
语音识别模型视频没有字幕时转写音频Whisper 兼容 /audio/transcriptions

每个槽位填三项：base_url（接入地址）、api_key、model（模型名）。只填一个槽位也能用——用不到的功能才需要对应 Key。

⌨️ 两种配置方式

  1. 界面：「设置 → LLM 配置」，填好保存即生效（改完无需重启）。
  2. 环境变量：推理槽 SUMMARY_API_KEY / SUMMARY_BASE_URL / SUMMARY_MODEL，转写槽 ASR_API_KEY / ASR_BASE_URL / ASR_MODEL，写进仓库根目录的 .env 后重启服务生效。旧名 LLM_API_KEY / OPENAI_API_KEY 等继续有效（兼容别名，日志会提示一次更名）。
Key 的安全：API Key 以 Fernet 加密落库（密文前缀 enc:v1:），加密密钥独立存放；接口只回掩码值，绝不会明文返回。也可以用「LLM 配置 → 从 .env 导入」一次性迁入。

🪶 不配置也能用

未配置任何 Key 时任务不会失败：自带字幕的视频照常出完整笔记；没有字幕的视频仍会产出转写原文（.txt / .srt），只是跳过总结步骤，处理过程里会明确标注 summarize_skipped——不会静默缺产物。

补上 Key 后：在历史任务里点「重新生成」即可得到完整笔记，转写部分命中缓存不会重复计费。
05

任务状态与结果

历史任务页展示全部任务（支持全文检索与标签筛选），右侧是所选任务的详情、产物与操作。

🔄 状态与可用操作

状态含义可用操作
等待中已排队，按并发上限依次执行取消（立即终止）
运行中显示当前阶段与实时进度停止（当前阶段边界中止）
已完成产物就绪查看 / 编辑 / 导出 / 重新生成 / 删除
失败显示脱敏后的可行动错误文案重试 / 删除
已停止被手动取消重试 / 删除

停止只请求、不强杀：运行中的任务在当前阶段（下载 / 转写 / 总结）结束边界安全中止，不会留下半写的产物文件。

📄 产物五件套

每个任务的产物都在 output/<任务id>/ 下（Docker 在 /output）：

  • <id>.summary.md —— 结构化 Markdown 总结（主产物）；
  • <id>.txt —— 转写 / 字幕全文；
  • <id>.srt —— 带时间戳的 SRT 字幕；
  • <id>.segments.json —— 分段信息；
  • <id>.polished.txt —— 润色后的文本（开启文本润色时才有）。

控制台里可直接预览；「导出」下载为 Markdown 附件（本版不提供 PDF 导出）。

✏️ 编辑总结 / 重试

  • 编辑总结：详情页直接修改总结并保存，覆盖写回产物文件，显示「已编辑 · 时间」徽标。
  • 重试 / 重新生成：清空该任务产物目录后从头执行（转写不会命中旧缓存）；可在重试时更换总结模板，其余配置取当前全局默认。
  • 编辑稿会随重新生成失效——重试 = 放弃编辑稿、按新配置重新产出；编辑徽标同步清零。
  • 删除任务：清理任务记录与产物目录，不影响你自己的本地源文件（浏览器上传的源文件会连带回收）。

🔍 检索与备份

  • 全文检索：搜索框可命中转写正文与总结内容（带高亮片段），也支持按标题 / 链接匹配。
  • 标签筛选：按标签过滤历史列表；标签支持重命名、合并、删除。
  • 导出 / 导入历史：把全部任务 + 标签 + 自定义模板 + 产物打包成 zip 下载，「导入历史」还原到另一台机器（已存在的任务自动跳过）——换机 / 备份推荐用它。
06

设置

「任务默认」是所有新任务的公共配置；LLM 配置见第四章，标签管理在历史任务页。

📝 任务默认

  • 总结模板：新任务的默认模板（创建时仍可按次覆盖）。
  • 字幕策略：自动（默认，人工字幕优先、自动字幕兜底）/ 仅人工字幕 / 关闭（始终下载音频 + 转写）。
  • 字幕语言：默认自动（中文优先，英文兜底）；也可指定 en / zh 等语言代码。
  • 音频格式：转写前抽取的音频格式（Web 默认 mp3，文件更小）。
  • 文本润色：默认关。开启后转写稿先经推理模型润色一遍再总结（多一次 LLM 调用，产物多一份 .polished.txt）。

🍪 浏览器 cookies（解锁登录内容）

需要登录态的视频内容（B 站 AI/CC 字幕、会员视频，YouTube 自动字幕 / 会员内容），本版不内置任何扫码登录，由你提供 cookies：

  • 浏览器 cookies（推荐）：在「设置 → 网络与访问」选择你已登录的浏览器，VTS 直接读取该浏览器的登录态。选好后点「测试读取」可预检——只显示域名计数与登录态提示，绝不回传 cookie 值。
  • cookies 文件：环境变量 VTS_COOKIES_FILE 指向 cookies.txt（等价 CLI --cookies）；与浏览器 cookies 互斥，显式文件优先。
  • macOS Chromium 系浏览器首次读取会弹钥匙串授权，点「始终允许」；Safari 需给终端「完全磁盘访问权限」。 Windows 直接读取，无需额外授权。
cookies 等同账号凭据：注意保管，不要提交进仓库、不要写进会外发的文件；仅限个人使用并遵守平台服务条款。

🌐 网络与运行

  • 网络代理：填 http:// / socks5:// 等代理地址（留空 = 直连），访问受限站点时使用。
  • 自定义 User-Agent：环境变量 VTS_USER_AGENT，非浏览器 UA 可绕过按 UA 信誉发起的 B 站 412 挑战（见常见问题）。
  • 并发上限：环境变量 VIDEO_TO_SUMMARY_MAX_CONCURRENT（默认 2）——同时运行的任务数。
  • 单任务超时：VIDEO_TO_SUMMARY_JOB_TIMEOUT（秒，默认 0 = 不限），超时任务按失败收尾。
  • 上传大小上限：VTS_UPLOAD_MAX_MB（默认 2048）。
单进程模型：VTS Web 是 single-process / single-worker 设计，请勿用 uvicorn --workers>1 或多副本部署（第二个进程会被数据目录锁拒绝启动，详见数据与隐私）。
07

常见问题

点开问题查看答案；没找到答案时，用「设置 → 导出日志」下载已自动脱敏的诊断日志再排查或求助。

下载被拦截：B 站 412 / YouTube 429 怎么办？
这是站点风控 / 限流，不是故障。三个解法任选：① 设置环境变量 VTS_USER_AGENT=Wget/1.21.3（非浏览器 UA，可绕过按 UA 信誉发起的 412 挑战）；② 提供登录 cookies——VTS_COOKIES_FILE 指向 cookies.txt 或用「设置 → 浏览器 cookies」；③ 配置代理后重试。Docker 部署详见仓库 docker/README.md「网络与风控」。
提示「no usable subtitle」/ B 站 AI 字幕拿不到？
B 站 AI/CC 字幕通常需登录才能获取，YouTube 自动字幕对匿名访问也会定点限流。在「设置 → 浏览器 cookies」选一个已登录对应站点的浏览器（或设 VTS_COOKIES_FILE）后重试；命中字幕的任务更快且零转写成本。
任务失败提示「LLM 调用被拒绝（认证失败）」？
到「设置 → LLM 配置」逐项检查：API Key 是否填对、base_url 是否以 http(s):// 开头、模型名是否是该端点支持的拼写（如 deepseek-chat）。自建 / 第三方兼容端点需确认它支持所用模型。排查无果时导出脱敏日志求助。
任务生成了转写但没有总结？
这是无 Key 降级：推理槽没配 Key 时只出转写（.txt / .srt），处理过程里有 summarize_skipped 标注。补好 Key 后点「重新生成」即可，转写部分走缓存不会重复消耗。
浏览器上传失败？
常见原因：① 文件类型不在支持列表（音视频扩展名白名单）；② 超过大小上限（默认 2048MB，可用 VTS_UPLOAD_MAX_MB 调整）。远程部署还可以改用「本地文件」路径直读——前提是该路径在服务端机器上可见。
如何更换端口 / 数据在哪？
端口：bash scripts/web.sh --port 8090 或环境变量 PORT=8090；端口被占用时会自动顺延。数据位置：源码运行为仓库根 data/app.db 与 output/；pip 安装在平台用户数据目录（macOS ~/Library/Application Support/VTS/、Windows %LOCALAPPDATA%\VTS\、Linux ~/.local/share/vts/）；Docker 在 volume /data 与 /output。详见数据与隐私。
转写 / 总结能加速吗？
优先命中字幕（零下载、零转写）：配好浏览器 cookies 让 B 站 / YouTube 的登录字幕可用；字幕策略保持「自动」。确需转写时选择就近的 Whisper 端点；总结耗时取决于推理端点的响应速度。调大 VIDEO_TO_SUMMARY_MAX_CONCURRENT 可并行跑多个任务。
08

数据与隐私

所有数据都保存在你自己的机器上；VTS 没有任何云端存储、遥测或用量上报。

📁 数据目录

形态位置
源码运行<仓库根>/data/app.db + <仓库根>/output/
pip 安装macOS ~/Library/Application Support/VTS/ · Windows %LOCALAPPDATA%\VTS\ · Linux ~/.local/share/vts/
Dockervolume /data/app.db + /output

均可用 VIDEO_TO_SUMMARY_DB / VIDEO_TO_SUMMARY_OUTPUT_DIR 覆盖。数据库存任务历史与配置，output/<任务id>/ 存产物文件。

🔒 安全说明

  • API Key 加密落盘：Fernet 加密（enc:v1: 前缀），加密密钥独立存放；接口只回掩码；数据库文件权限 0600。
  • 诊断日志自动脱敏：导出的日志已抹去 Key / 密文 / token / cookie / URL 凭据 / 主目录路径，可放心外发。
  • 暴露局域网 / 公网前必须设 Token：环境变量 VIDEO_TO_SUMMARY_TOKEN，设置后所有 /api/v1 请求需带 Bearer Token；默认只监听 127.0.0.1。
  • 单进程约束：任务调度 / 取消 / 启动恢复都要求单一进程；第二个进程对同一数据目录启动会被运行锁明确拒绝（勿用 --workers>1、多副本容器或共用数据目录）。
  • 备份迁移：用「导出历史 / 导入历史」打包还原；或停服后整目录复制数据目录与产物目录。
09

能力边界

VTS 刻意保持单用户、BYOK 形态。可选能力由插件声明，以 GET /api/v1/capabilities 的返回为准；本构建不含任何插件，响应为空对象。

🚧 明确不做的事

  • 不内置本地转写——转写只走你配置的 OpenAI 兼容 Whisper API，不下载本地模型；
  • 不内置站点登录集成——没有扫码登录，需要登录态的内容用 cookies 自行提供；
  • 无 PDF 导出——产物导出为 Markdown；历史整体导出 / 导入为 zip；
  • 单用户——无账号体系、无多租户、无用量看板；
  • 产物不加水印——输出即原始标准文件。

其中部分能力（如 PDF 导出）可经插件挂载点扩展（vts.plugins entry points）；完整的范围取舍见仓库 CONTRIBUTING.md「范围宣言」。
